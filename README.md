# Interactive Terminal Quiz App 🎯

Program kuis interaktif berbasis Command Line Interface (CLI) yang dibuat menggunakan Python. Project ini merespons input pengguna secara *real-time*, menghitung skor, dan memberikan umpan balik di akhir kuis.

## 🚀 Fitur Utama
- **Kuis Interaktif:** Pertanyaan disajikan satu per satu via terminal.
- **Validasi Input:** Memastikan pengguna memasukkan pilihan yang valid.
- **Sistem Skor:** Perhitungan skor otomatis berdasarkan jawaban benar.
- **Umpan Balik Kuis:** Menampilkan skor akhir dan evaluasi performa.

## 🛠️ Teknologi
- **Bahasa Pemrograman:** Python 3.x
- **Library:** Standard Library (`sys`, `random`, dll.)
